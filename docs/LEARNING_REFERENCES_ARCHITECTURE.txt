Proposed resource model
A small versioned manifest in dist/learning-references.mjs contains independent learning resources. It is shipped with the website through code review and release approval; this phase has no authoring interface or database collection. It is separate from vocabularySets, Units and Teacher Voice.

Each record contains:
- id: stable slug, e.g. number-chart-0-100.
- published: true for reviewed public entries; deleted/unpublished entries are excluded from listing and reader lookup.
- title and chineseTitle: display names.
- description and altText: resource-specific accessible descriptions.
- topicIds: one or more CURRENT topic IDs, normalised by the existing catalogue setTopics() function. This reuses the canonical multi-topic order/validation and makes no new taxonomy.
- yearLevels: null means All year levels; an explicit list can limit later resources to existing Prep–Year 6 levels. All-year references remain visible when a year filter is active.
- assets.png: required preview; optional assets.svg for scalable viewing and assets.pdf for printing. Only reviewed same-site asset paths under assets/learning-references/ are accepted. No remote HTML or script schemes.
- internal normalised type: learning-reference, with no vocabulary items or audio records.

Only one manifest record is implemented: Number Chart 0–100 / 数字表 0–100, topicIds [numbers], all year levels. The data fields and image/PDF assets can also represent future maps, diagrams, calendars and printable sheets without new top-level navigation or topic structures, but none of those resources/types is implemented in this phase. New content would require its own approval.

Publishing semantics
The manifest is a public static release mechanism, not a security boundary for private drafts. Only approved public assets should be included in the Hosting payload; hiding a card is not intended to protect a file. A future Admin/editor or dynamic publishing backend is explicitly outside this phase.

Page behaviour
- Individual Topic header.
- Learning References, only if a published reference matches that topic/year.
- Vocabulary Sets, using the existing cards and published metadata.
- Existing public Units retained after Vocabulary Sets so no prior resource disappears.
- No added arrows or decorative navigation badges on reference cards.
- Topics landing cards also remain navigable for a reference-only topic and use plain All year levels text.
- Reference route is #/reference?id=...&topic=...; Topics remains the active top-level tab. Invalid IDs show Reference unavailable, and invalid parent topics resolve to an associated topic.
- Card preview opens an anonymous reader. Fit/enlarge, contained horizontal/vertical scrolling, full-size SVG link and printable A4 PDF link are available. Native full screen is attempted when supported; otherwise the chart uses a full-window overlay. Exit button/Escape restores focus and scrolling. Background controls are inert while the overlay is active.
- Later vocabulary/unit fetches do not reset the reference's zoom or full-window state. No student sign-in is required.
